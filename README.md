# Joao Carlos Portfolio (React 19 + Vite)

This project is a React 19 single-page application migrated from Astro.

## Stack

- React 19
- TypeScript (strict)
- Vite
- TanStack Router
- TanStack Query
- Linaria
- Native fetch

## Routes

- `/`
- `/stack`
- `/experience`

## Commands

All commands run from the project root:

| Command | Action |
| :-- | :-- |
| `pnpm install` | Install dependencies |
| `pnpm run dev` | Start local dev server |
| `pnpm run typecheck` | Run strict TypeScript check |
| `pnpm run build` | Build production assets to `dist/` |
| `pnpm run preview` | Preview production build |
